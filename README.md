# Habit Tracker

A simple habit tracker built with plain HTML, CSS, and JavaScript. No build step, no dependencies.

## Features

- Add and delete habits
- Mark today as done with one click
- Current streak counter
- 12-week heatmap per habit; click any past day to fix your history
- Data saved in your browser with `localStorage`
- Light and dark mode follow your system setting

## Run it

Open `index.html` in your browser. That's it.

## Project structure

```
habit-tracker/
├── index.html   # page markup
├── style.css    # styles and heatmap grid
├── script.js    # state, streaks, rendering
└── README.md
```
